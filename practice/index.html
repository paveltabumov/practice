Практика

Практическая часть состоит из трёх блоков: Word, Excel и VBA. Все задания привязаны к вашему варианту — узнайте его у преподавателя и используйте во всех заданиях.

ℹ️
Сначала — вариант

Номер варианта выдается преподавателем в начале практики. Он используется во всех заданиях: в именах файлов, листов, макросов.

📝

Word

Оформление документов: стили, оглавление, таблицы, формулы, макросы.

  • W-01. Комплексное форматирование Титульный лист, оглавление, колонтитулы
  • W-02. Тестовое задание WinWord Колонки, буквица, таблицы, WordArt
📊

Excel

Таблицы, формулы, сводные, диаграммы, макросы.

  • X-01. Формулы и автозаполнение Сортировка, автосумма, МАКС/МИН
  • X-02. Сводные таблицы Классный журнал, ведомость итогов
  • X-03. Макросы: расходы Запись, VBA, кнопки на листе
  • X-04. Диаграммы и «что если» Формулы массива, три сценария курса
⌨️

VBA

Программирование в Excel: переменные, условия, циклы, функции.

  • V-01. Переменные и типы Dim, диапазоны типов, Overflow
  • V-02. Условия: вознаграждение If…ElseIf, DateDiff, бонус за стаж
  • V-03. Условия: три задачи Электроэнергия, кирпич, абитуриенты
  • V-04. Циклы For…Next Сумма, комары, треугольник, вложенные
  • V-05. Процедуры и функции Окружности, прямоугольники
  • V-06. Стандартные функции Инициалы, замена, даты, преобразования

Что сдаётся

Для каждого блока — свой файл. Имя файла строгое, формат должен совпадать с указанным в задании.

Блок Файл Расширение
Word Практика_Word_Фамилия_Группа_В<вариант> .docx
Excel Практика_Excel_Фамилия_Группа_В<вариант> .xlsx
Excel с макросами (X-03, X-04) Практика_Excel_Фамилия_Группа_В<вариант> .xlsm
VBA Практика_VBA_Фамилия_Группа_В<вариант> .xlsm
⚠️
Расширение важно

Для заданий X-03, X-04 и всего блока VBA — именно .xlsm. Если сохранить как .xlsx, макросы и функции VBA потеряются, и работа не будет зачтена.

Внутри каждого файла

  • Колонтитул: ФИО, группа, номер варианта — на каждой странице.
  • Свойства документа: автор = ФИО; тема = «Практика Word / Excel / VBA».
  • Имена листов и модулей — с номером варианта (например, Расходы_В07).
  • Скриншоты ключевых шагов — 2–3 на задание.

Порядок выполнения

  1. Узнать свой вариант

    Номер варианта выдается преподавателем в начале практики.

  2. Прочитать теорию по блоку

    Короткие карточки в разделах Word, Excel, VBA.

  3. Выполнить задания блока

    По порядку: Word → Excel → VBA. После каждого пункта — сохранять файл.

  4. Сохранить с правильным именем

    Имя — по формату из таблицы выше. Проверить колонтитул и свойства.

  5. Сделать скриншоты

    2–3 на задание: видна команда, действие и результат.

  6. Оформить отчёт

    По требованиям в разделе «Отчёт».

  7. Защита

    Три случайных вопроса из «Вопросов к защите».
