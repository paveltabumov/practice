Теория

Справочник по трём инструментам практики: Word, Excel и VBA. Каждая тема — одна короткая карточка: зачем нужно, какие команды, типичные ошибки и чек-лист. Читать всё подряд не нужно — открывайте тему, которая нужна прямо сейчас.

📖
Как читать теорию

Внутри каждой части темы идут по порядку практических заданий. Если вы выполняете задание W-03 — откройте Word, найдите тему про таблицы. Остальное читать не обязательно.

📝

Word

Текстовый процессор: форматирование, стили, таблицы, формулы, макросы.

  • Интерфейс и документ Вкладки, панели, режимы просмотра
  • Шрифт и абзац Гарнитура, размер, отступы, интервалы
  • Стили и оглавление Стили заголовков, автособираемое содержание
  • Страница и колонтитулы Поля, ориентация, нумерация, верхний колонтитул
  • Списки Маркированные, нумерованные, многоуровневые
  • Таблицы Создание, объединение ячеек, формулы
  • Рисунки и объекты Картинки, обтекание, буквица, WordArt
  • Колонки Многоколоночная вёрстка, разделитель
  • Формулы Редактор Microsoft Equation
  • Макросы Запись макроса, назначение клавиш
📊

Excel

Табличный процессор: формулы, ссылки, сводные таблицы, диаграммы, макросы.

  • Интерфейс и лист Ячейка, диапазон, строка формул, листы
  • Типы данных Числа, текст, даты, логические значения
  • Ссылки Относительные, абсолютные, смешанные, F4
  • Формулы Операторы, ошибки, порядок вычислений
  • Встроенные функции СУММ, ЕСЛИ, СРЗНАЧ, МАКС, МИН, Мастер функций
  • Сортировка и фильтры Автофильтр, сортировка по нескольким столбцам
  • Сводные таблицы Создание, поля, итоги
  • Диаграммы Мастер диаграмм, типы, модификация
  • Макросы Запись, кнопки, меню, панели
  • Печать и область печати Разметка, область печати, колонтитулы
⌨️

VBA

Программирование в Excel: переменные, условия, циклы, процедуры и функции.

  • Редактор VBA Модули, окно проекта, окно отладки
  • Переменные и типы данных Dim, Byte, Integer, Long, Single, Double, String, Date
  • Константы Const, области видимости
  • Операторы Арифметика, Mod, целочисленное деление
  • InputBox и MsgBox Ввод данных и вывод сообщений
  • Условия If…Then…Else, IIf, Select Case
  • Циклы For…Next, вложенные циклы
  • Процедуры и функции Sub, Function, вызов, область видимости
  • Стандартные функции: математика Abs, Sgn, Fix, Int, Rnd
  • Стандартные функции: строки Left, Right, Mid, InStr, Replace, LCase
  • Стандартные функции: даты Day, Month, Year, DateDiff, DateAdd
  • Преобразование типов и форматов CStr, CInt, Val, Format
