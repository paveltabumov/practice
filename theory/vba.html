VBA

Справочник по языку Visual Basic for Applications в Excel. Темы идут в порядке практических заданий: переменные, условия, циклы, процедуры и функции, стандартные функции.

📖
Как читать код

Все примеры в карточках — минимальные. Полные процедуры и задания смотрите в разделе «Практика VBA». Там же разбирается работа с ячейками Excel (Range, Cells). Примеры можно копировать в модуль и проверять.

Редактор VBA

Код пишется не в Excel, а в отдельном окне — редакторе Visual Basic. Открывается из любой книги Excel.

🔧 Ключевые панели
  • Project — дерево проекта: модули, листы, формы
  • Properties — свойства выделенного объекта
  • Code — окно с кодом
  • Immediate — окно отладки, вывод через Debug.Print
⌨️ Клавиши
  • Alt+F11 — открыть / закрыть редактор
  • Ctrl+G — окно Immediate
  • F5 — запустить процедуру
  • F8 — шаг с заходом в процедуры
  • F9 — поставить / снять точку останова
⚠️ Частые ошибки
  • Код написан в модуле листа, а не в обычном модуле.
  • Модуль не переименован — потом сложно найти нужный.
  • Option Explicit отключён — опечатки в именах не отлавливаются.
✅ Чек-лист
  • Модуль создан через Insert → Module
  • Модуль назван осмысленно
  • В начале модуля стоит Option Explicit

Переменные и типы данных

Переменная — именованная ячейка памяти для значения. Объявляется через Dim, тип задаётся ключевым словом.

🔧 Основные типы
  • Byte — 0…255
  • Integer — −32 768…32 767
  • Long — ±2,1 млрд
  • Single, Double — дробные
  • Currency — деньги
  • String — текст
  • Boolean — True / False
  • Date — дата и время
  • Variant — «любой», по умолчанию
🔧 Объявление
  • Dim A As Integer
  • Dim A%, B&, C@ — сокращённо
  • Const Pi = 3.1415 — константа
  • Public A As Byte — видна во всём проекте
  • Private A As Byte — только внутри модуля
⚠️ Частые ошибки
  • Число не влезает в выбранный тип — ошибка Overflow.
  • Byte вместо Integer для отрицательных значений.
  • Переменная без объявления, а Option Explicit включён.
✅ Чек-лист
  • Все переменные объявлены
  • Типы соответствуют диапазону значений
  • Константы вынесены в Const

Константы

Константа — значение, которое не меняется при выполнении программы. Объявляется через Const.

🔧 Синтаксис
  • Const Pi = 3.1415
  • Const S = 100, Price = 300
  • Const Rent = S * Price — вычисляемая на этапе компиляции
  • Public Const Pi = 3.1415 — видна из всех модулей
⚠️ Частые ошибки
  • Попытка присвоить константе новое значение — ошибка компиляции.
  • Константа объявлена внутри процедуры — недоступна из других.
  • Ожидали, что Const Rent = S * Price пересчитается при изменении S — не пересчитается.
✅ Чек-лист
  • Константы в разделе объявлений модуля, если нужны в нескольких процедурах
  • Имена констант осмысленны
  • Значения не меняются по ходу программы

Операторы

Арифметика, сравнение, логика. Приоритет — как в математике: сначала скобки, степень, умножение/деление, потом сложение/вычитание.

🔧 Арифметика
  • +, -, *, / — как обычно
  • \ — целочисленное деление: 7 \ 2 = 3
  • Mod — остаток: 7 Mod 2 = 1
  • ^ — степень: 2 ^ 3 = 8
  • & — сцепка строк
🔧 Сравнение и логика
  • =, <>, <, >, <=, >=
  • And, Or, Not
  • Is — сравнение объектов
⚠️ Частые ошибки
  • Путают / и \: 7 / 2 = 3.5, а 7 \ 2 = 3.
  • Забыли, что результат Mod для отрицательных чисел отрицательный.
  • And применён к числам, а не к логическим значениям.
✅ Чек-лист
  • Порядок операций расставлен скобками, если есть сомнения
  • Целочисленное деление и остаток — там, где нужно
  • Логические операторы — только над Boolean

InputBox и MsgBox

InputBox запрашивает значение у пользователя, MsgBox показывает сообщение. Это базовый ввод/вывод в VBA.

🔧 InputBox
  • x = InputBox("Введите число")
  • InputBox("Введите", "Заголовок", "Значение по умолчанию")
  • Возвращает строку — при необходимости преобразовать
🔧 MsgBox
  • MsgBox "Готово"
  • r = MsgBox("Вопрос?", vbYesNo + vbQuestion, "Заголовок")
  • Возвращает код нажатой кнопки: 6 — Да, 7 — Нет, 2 — Отмена
⚠️ Частые ошибки
  • InputBox вернул строку, а код ждёт число — Runtime error.
  • Пользователь нажал «Отмена» — пустая строка ломает логику.
  • Сообщение на английском, а контекст — русский.
✅ Чек-лист
  • Ввод проверен на пустое значение и «Отмена»
  • Числа преобразованы через Val или CInt
  • Окна сообщений с понятными заголовками

Условия

Ветвление выполняется оператором If…Then…Else и оператором выбора Select Case.

🔧 If…Then…Else
  • If x > 0 Then MsgBox "плюс"
  • If x > 0 Then … Else … End If
  • If … ElseIf … Else … End If — цепочка
  • IIf(условие, да, нет) — короткая форма
🔧 Select Case
  • Select Case x → Case 1, Case 2, Case Else
  • Case Is > 0 — сравнение
  • Case 1 To 5 — диапазон
  • Case 1, 3, 5 — перечисление
⚠️ Частые ошибки
  • Забыли End If или End Select.
  • Условие записано как If 1 < x < 5 — так нельзя, нужно And.
  • Перепутан порядок ElseIf — срабатывает не та ветвь.
✅ Чек-лист
  • Все ветви закрыты End If / End Select
  • Составные условия — через And / Or
  • Есть Case Else или Else на непредвиденный случай

Циклы

Цикл повторяет блок кода. В базовом курсе используется For…Next; он же применяется для вложенных циклов.

🔧 Синтаксис
  • For i = 1 To 10 … Next i
  • For i = 10 To 1 Step -1 … Next i — обратный счёт
  • For Each x In коллекция … Next x
🔧 Вложенные циклы
  • Внешний i, внутренний j
  • Внутренний выполняется полностью за один шаг внешнего
  • Пример: треугольник из чисел, таблица умножения
⚠️ Частые ошибки
  • Забыли Next i — код не запускается.
  • Переменная цикла после Next остаётся на последнем значении + 1.
  • Изменение переменной цикла внутри тела — бесконечный цикл.
✅ Чек-лист
  • Все For закрыты Next
  • Шаг задан, если он не равен 1
  • Вложенные циклы используют разные переменные

Процедуры и функции

Sub выполняет действия, ничего не возвращает. Function возвращает значение и может использоваться прямо в ячейках Excel.

🔧 Sub и Function
  • Sub Имя() … End Sub — процедура
  • Function Имя(Арг As Тип) As Тип … End Function
  • Возврат значения: Имя = … внутри функции
  • Аргументы — по значению (ByVal) или по ссылке (ByRef)
⌨️ Область видимости
  • Public — из любого модуля
  • Private — только внутри модуля
  • По умолчанию — Public
⚠️ Частые ошибки
  • Функция не возвращает значение — Excel показывает 0.
  • ByRef вместо ByVal — изменился аргумент вызывающей стороны.
  • Процедура помечена Private, а вызывается из другого модуля.
✅ Чек-лист
  • Функция возвращает значение явно
  • Область видимости выбрана осознанно
  • Имена процедур — глаголы, функций — существительные

Стандартные функции: математика

Готовые математические функции VBA — не нужно писать свои.

🔧 Функции
  • Abs(x) — модуль
  • Sgn(x) — знак: −1, 0, 1
  • Fix(x) — отбрасывает дробную часть
  • Int(x) — округляет вниз
  • Rnd() — случайное от 0 до 1
  • Round(x, n) — округление до n знаков
⚠️ Частые ошибки
  • Путают Fix и Int для отрицательных чисел: Fix(-3.7) = -3, Int(-3.7) = -4.
  • Rnd без Randomize даёт одинаковую последовательность.
✅ Чек-лист
  • Знак и округление проверены на отрицательных значениях
  • Randomize вызван перед первым Rnd

Стандартные функции: строки

Работа с текстом: выделение части, поиск, замена, изменение регистра.

🔧 Функции
  • Len(s) — длина
  • Left(s, n) — первые n символов
  • Right(s, n) — последние n символов
  • Mid(s, start, len) — подстрока
  • InStr(s, подстрока) — позиция первого вхождения
  • Replace(s, что, на что) — замена
  • LCase(s) / UCase(s) — регистр
  • StrReverse(s) — разворот строки
  • Trim(s) — убрать пробелы по краям
⚠️ Частые ошибки
  • Нумерация символов в строке — с 1, а не с 0.
  • Mid с недостаточной длиной возвращает строку короче ожидаемой.
  • InStr вернул 0 — подстрока не найдена; это не ошибка, а сигнал.
✅ Чек-лист
  • Проверка на пустую строку и Nothing
  • Позиции и длины пересчитаны верно
  • Регистр приведён к нужному

Стандартные функции: даты

Даты в VBA — отдельный тип Date. Есть готовые функции для получения компонентов и вычисления разницы.

🔧 Функции
  • Date — текущая дата
  • Now — дата и время
  • Day(d), Month(d), Year(d)
  • DateDiff("m", d1, d2) — разница в месяцах
  • DateAdd("m", 2, d) — прибавить 2 месяца
  • Weekday(d) — день недели
⚠️ Частые ошибки
  • Дата введена как строка — операции с ней дадут ошибку.
  • Перепутаны порядок аргументов DateDiff.
  • Интервал задан кириллицей ("м") вместо "m".
✅ Чек-лист
  • Даты введены через #дд.мм.гггг#
  • Интервалы DateDiff — латиницей
  • Проверены граничные случаи (конец месяца, года)

Преобразование типов и форматов

Часто нужно превратить строку в число, число — в текст, дату — в удобный формат.

🔧 Функции
  • CStr(x) — в строку
  • CInt(x), CLng(x) — в целое
  • CSng(x), CDbl(x) — в дробное
  • CDate(s) — в дату
  • Val(s) — из строки в число (терпимо к мусору)
  • Format(x, "Currency") — денежный формат
  • Format(x, "#.#") — один знак после запятой
  • Format(x, "#%") — проценты
⚠️ Частые ошибки
  • CInt("12abc") выдаст ошибку, а Val("12abc") вернёт 12.
  • Format возвращает строку — не путать с числом.
  • При сцепке строк и чисел забывают CStr.
✅ Чек-лист
  • Преобразование явное, не «по умолчанию»
  • Ввод пользователя проверяется перед преобразованием
  • Форматы применяются к финальному выводу
